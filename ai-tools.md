# AI Coding Tool Exploration

## 1. Which AI tool did you explore?
I explored ChatGPT as an AI coding tool.

## 2. How can it help a web developer?
ChatGPT can help web developers by:
- Generating code snippets
- Explaining complex concepts
- Debugging errors
- Suggesting best practices
- Helping in learning new technologies

## 3. Can AI-generated code contain mistakes?
Yes, AI-generated code can contain mistakes. It may produce incorrect logic, outdated methods, or incomplete solutions. 
Developers should always review and test the code.

## 4. Why should developers understand code instead of copying it directly?
Developers should understand code because:
- It helps in debugging errors
- Improves problem-solving skills
- Prevents misuse of incorrect code
- Builds strong programming knowledge
