## Questions & Answers

### 1. Why is MERN called a full-stack JavaScript stack?
MERN is called a full-stack JavaScript stack because it uses JavaScript for both frontend and backend development.
React is used for frontend, while Node.js and Express are used for backend, and MongoDB is used for the database.

---

### 2. What is one major difference between Node.js, Laravel, and Django?
The main difference is the programming language they use. Node.js uses JavaScript, Laravel uses PHP, and Django uses Python.

---

### 3. Which framework would you personally like to explore after MERN?
I would like to explore Django because it provides many built-in features and is very secure and structured.

---

### 4. Why will MERN be the primary stack used in this course?
MERN is used because it allows developers to use a single language (JavaScript) for the entire application. 
It is modern, fast, and widely used in industry.
