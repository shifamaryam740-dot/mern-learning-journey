MongoDB 
MongoDB is a data based system that stores flexible and semi structured data.
It is an NoSQL database uses documents instead of tables.
MongoDB Atlas is a cloud based version of MongoDB.
MongoDB Compass is a visual tool to manage MongoDB

Express.js 
It is a web frame work for Node.js to build web applications.
It is used on the backend to send response.
It makes it very easy to build APIs by managing routes. 

React
React is a JavaScript  used to build user interfaces also helps create websites and web apps. 
it is used on the fronted.
A component is a small reusable piece of UI. Each website can make a separate component.
Reusable components save time and make code better.

Node.js
Node.js is a JavaScript runtime environment. It allows you to run JavaScript outside the browser.
Yes, it allows JavaScript to run outside the browser. 
npm (Node Package Manager) is a tool that comes with Node.js. It is used to run scripts. 
It acts as the backend to runs the server and connects to MongoDB database
